# Muutzin! Lactería – sitio web

Sitio estático (HTML, CSS y JS en `index.html`, imágenes en `img/`) para Muutzin! Lactería, Morelia, Mich.

- Tienda con carrito, entrega (tienda o domicilio) y pago; el pedido se confirma por WhatsApp.
- Sección de mayoristas con cotización por WhatsApp.
- Configuración (WhatsApp, horario, envío, link de pago) en el bloque `CONFIG` al inicio del `<script>`.

Publicado con GitHub Pages desde la rama `main`.
